# Meshy 使用指南

## 输入来源

Meshy输入包应由已锁定的 Concept/Hull Concept 和 `integration.yaml` 导出。

## ShipType_SmallSailer01 当前原则

- 目标：Hull Base；
- 不使用展开大帆；
- 帆省略或收帆；
- 简化索具；
- 删除木桶、绳圈和小杂物；
- 保留V0.8船首与船尾轮廓；
- 强调一个大货舱口、低矮两层艉楼、中线舵和主桅中心线。
- 可分件出毛坯；**不要**把分件当成 UE 最终模块。UE 帆装是 MastRig 整包。

## 输出

```text
assets/ships/ShipType_SmallSailer01/meshy/
```
