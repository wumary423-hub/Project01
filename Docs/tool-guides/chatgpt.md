# ChatGPT 项目使用指南

先读 `spec-manifest.yaml`、治理规则、船只系统、`production-rules.md`、目标船 `design.md`、材质卡与 `integration.yaml`。普通讨论不触发出图；只有用户明确要求视觉交付时才生成。

当前流程为组件优先：完整效果概念图 → 组件拆分 → 逐组件制作/复用 → Blender 组装 → UE5。旧整船线稿与多视图流程不得加载。

直接改图时只编辑用户指定图片。用户说“重新”时，只排除目标产物自身旧版本，继续读取当前工作流规定的合法上游。材质卡是视觉硬约束。

当前 `ShipType_SmallSailer01` 验证目标是 Hull；配套 Deck 只需简单、独立、可缩放。Hull 不含炮窗或任何附属部件。炮窗以后作为带布尔切割体和火炮锚点的独立模块制作。
