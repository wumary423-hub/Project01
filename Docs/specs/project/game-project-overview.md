# 游戏项目概要

## 1. 项目类型

- UE5 单人独立开发项目；
- 以航海、海上贸易、探索和海战为主要内容；
- 开发内容分阶段增加，第一版避免引入难以控制的超复杂系统。

## 2. 世界与时代风格

- 技术与视觉基础来源于约15至17世纪欧洲航海时代；
- 世界使用架空国家和架空地理；
- 不要求逐项复原某一个真实国家或历史船型；
- 历史合理性服务于可读性、世界观一致性和游戏性。

## 3. 资产原则

- 常规观察 50–200m；约 10m 为极限近距，两档不冲突；
- 优先轮廓、比例、甲板层级和主要模块；
- 小型装饰几何必须证明具有视觉或游戏价值；
- 3D船只资产与2D岗位布局资产必须一致。

## 4. 当前范围

本文件只记录与船只资产规范直接相关的项目背景。其他系统应建立各自的系统规范，不应在本文件中无限扩展。
