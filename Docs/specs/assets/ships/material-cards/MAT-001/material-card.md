# MAT-001｜写实历史木帆船基础材质

本卡是“游戏船只资产”的默认木质帆船材质基准。除非某艘船明确指定专属材质卡，否则概念图、概念多视图与最终多视图均应使用 MAT-001。

> 本卡只约束材质、色彩、粗糙度、旧化和表面质感，不得修改船型结构、桅杆数量、炮窗数量、甲板层级、船楼、舵、货舱口等结构设计。

## 1. 总体方向

- 写实、历史感、长期海上使用后的自然旧化。
- 主关系：暖棕中低明度木材 + 深色板缝/结构件 + 低饱和灰白帆布。
- 主要旧化来源：盐雾、日晒、潮湿、踩踏/摩擦、焦油与防水处理。
- 状态必须读成“正在使用并持续维护”，不是沉船、废墟或奇幻夸张旧化。
- 避免高饱和、塑料感、统一光滑表面与大面积鲜红橙锈。

## 2. 船壳外板 / 主木材

- 色相：深暖棕至胡桃棕，纵向木纹清晰，板缝明显更深。
- 参考色：`#85654C` `#695141` `#534034` `#3F2F26` `#251D18`。
- 表面：油脂、树脂或传统防水处理后的哑光至半哑光。
- PBR 建议：Roughness 约 `0.55–0.75`；高频摩擦边缘可略低，缝隙/老化区更高。
- 旧化：水线、阴影与积水区明显更暗；可有盐渍、潮湿发暗和少量污垢，但必须保留木纹。

## 3. 甲板 / 栏杆 / 上层木构件

- 与船壳同一木材体系，但因日晒、干燥和踩踏稍亮、稍暖。
- 参考色：`#8A6547` `#6F4D35` `#4A3326`。
- PBR 建议：Roughness 约 `0.50–0.70`。
- 扶手、梯级、走道边缘允许轻微磨光；积水死角局部发暗。

## 4. 帆布

- 灰白/象牙灰，禁止纯白新布感。
- 参考色：`#DADBD7` `#CBCCC8` `#B7B9B4` `#9A9C99`。
- 厚亚麻/棉帆布质感；必须可见织物纤维、拼接缝、自然褶皱。
- PBR 建议：Roughness 约 `0.75–0.90`，以漫反射为主；逆光可有轻微透光。
- 缝线、折痕、下缘和绳索接触处可轻度泛黄、积灰、留盐痕。

## 5. 索具

### 站索 / 固定索具

- 焦油处理的深褐至近黑，比活动索明显更深。
- 参考色：`#241F1A` `#151412` `#34302A`。
- PBR 建议：Roughness 约 `0.65–0.85`；纤维粗糙，但焦油区允许极弱油润反光。

### 活动索 / 麻绳

- 天然麻色、土黄褐色。
- 参考色：`#8B7658` `#6D5C45` `#4F4435`。
- PBR 建议：Roughness 约 `0.75–0.90`。
- 长期摩擦处可变浅、起毛；受潮处局部变深。

## 6. 铁件 / 链条 / 紧固件

- 黑铁或深灰旧铁，禁止抛光钢感。
- 参考色：`#252627` `#151617` `#4A4641`。
- PBR 建议：Metallic `0.80–1.00`，Roughness `0.50–0.75`；磨损边缘允许少量亮边。
- 锈蚀以棕黑氧化与盐雾侵蚀为主，红橙锈只做少量点缀。

## 7. 水线 / 船底潮湿区

- 明显深于上部船壳，接近黑褐。
- 参考色：`#171513` `#0F1012` `#2C241E`。
- 允许潮湿暗亮、焦油感、水线色差、盐渍和轻微海洋附着物。
- Roughness 可在约 `0.45–0.80` 内不均匀变化，体现湿润与附着物差异。
- 禁止直接做成沉船式重度腐烂。

## 8. 生成与制作硬约束

1. 木材必须保留木纹、板缝和构造层次，禁止塑料般均匀表面。
2. 帆布默认低饱和灰白，有拼缝、褶皱和轻度污渍。
3. 站索深、活动索浅，两类索具不得混成一个色值体系。
4. 金属以旧黑铁为主，避免大面积鲜艳铁锈。
5. 旧化遵循功能逻辑：水线、积水、接触面、板缝和绳索摩擦处优先。
6. 整体维持可使用、受维护的船况。
7. 材质卡不得覆盖任何船只设计档案中的结构约束。

## 9. 在资产流程中的使用

- **[概念图]：** 锁定整体木材色相、帆布灰白、索具深浅关系和旧化尺度。
- **[概念多视图]：** 所有视角保持同一材质分区与同一旧化逻辑。
- **[最终多视图]：** 减少戏剧性光照，强化 PBR 材质可读性；由 MAT-001 约束材质，由线稿多视图约束结构。
