# MAT-001｜写实历史木帆船基础材质

本卡是“游戏船只资产”的默认木质帆船材质基准。除非某艘船明确指定专属材质卡，否则完整效果概念图、组件设计图与最终 3D 材质均应使用 MAT-001。

> 本卡只约束材质、色彩、粗糙度和表面质感，不得修改船型结构、桅杆数量、炮窗数量、甲板层级、船楼、舵、货舱口等结构设计。

## 1. 总体方向

- 写实、历史船舶制造语言；表面完整、干净、维护良好，不表现视觉老化。
- 主关系：暖棕中低明度木材 + 深色板缝/结构件 + 低饱和灰白帆布。
- 避免高饱和、塑料感与统一光滑表面。
- 禁止通过污渍、盐痕、褪色、磨损、锈蚀、腐烂、海洋附着物、泛黄、积灰等方式表现使用年限。

## 2. 船壳外板 / 主木材

- 色相：深暖棕至胡桃棕，纵向木纹清晰，板缝明显更深。
- 参考色：`#85654C` `#695141` `#534034` `#3F2F26` `#251D18`。
- 表面：油脂、树脂或传统防水处理后的哑光至半哑光。
- PBR 建议：Roughness 约 `0.55–0.75`。
- 表面保持完整、干净；不得添加用于表现年限的污迹、色斑、磨损或腐蚀效果。

## 3. 甲板 / 栏杆 / 上层木构件

- 与船壳同一木材体系，整体稍亮、稍暖。
- 参考色：`#8A6547` `#6F4D35` `#4A3326`。
- PBR 建议：Roughness 约 `0.50–0.70`。
- 保留清晰木纹、板缝和结构层次，表面完整干净。

## 4. 帆布

- 灰白/象牙灰，禁止纯白。
- 参考色：`#DADBD7` `#CBCCC8` `#B7B9B4` `#9A9C99`。
- 厚亚麻/棉帆布质感；必须可见织物纤维、拼接缝、自然褶皱。
- PBR 建议：Roughness 约 `0.75–0.90`，以漫反射为主；逆光可有轻微透光。
- 帆布保持干净完整，不添加泛黄、积灰、盐痕、污渍或磨损。

## 5. 索具

### 站索 / 固定索具

- 焦油处理的深褐至近黑，比活动索明显更深。
- 参考色：`#241F1A` `#151412` `#34302A`。
- PBR 建议：Roughness 约 `0.65–0.85`；保留绳索纤维质感，焦油表面允许极弱油润反光。

### 活动索 / 麻绳

- 天然麻色、土黄褐色。
- 参考色：`#8B7658` `#6D5C45` `#4F4435`。
- PBR 建议：Roughness 约 `0.75–0.90`。
- 保留天然绳纤维质感，颜色保持稳定，不表现摩擦变色、起毛或受潮变深。

## 6. 铁件 / 链条 / 紧固件

- 黑铁或深灰铁，禁止抛光钢感。
- 参考色：`#252627` `#151617` `#4A4641`。
- PBR 建议：Metallic `0.80–1.00`，Roughness `0.50–0.75`。
- 表面保持完整，不表现氧化、锈蚀、盐雾侵蚀或磨损亮边。

## 7. 船底 / 防水处理区

- 明显深于上部船壳，接近黑褐。
- 参考色：`#171513` `#0F1012` `#2C241E`。
- 表面表现深色传统防水处理，不使用潮湿污迹、水线盐渍或海洋附着物来制造色差。
- Roughness 约 `0.45–0.80`，用于表现防水处理本身的表面差异，不用于表现老化。

## 8. 生成与制作硬约束

1. 木材必须保留木纹、板缝和构造层次，禁止塑料般均匀表面。
2. 帆布默认低饱和灰白，不使用纯白；需要拼缝、褶皱和织物纤维。
3. 站索深、活动索浅，两类索具不得混成一个色值体系。
4. 金属以黑铁/深灰铁为主，表面完整，不添加锈蚀。
5. 禁止任何为了表现使用年限而添加的做旧效果，包括污渍、盐痕、褪色、磨损、锈蚀、腐烂、附着物、泛黄和积灰。
6. 整体保持干净、完整、维护良好的表面状态。
7. 材质卡不得覆盖任何船只设计档案中的结构约束。
8. 材质卡未规定的颜色不得自行添加；新增颜色必须先修改材质卡。

## 9. 在资产流程中的使用

- **完整效果概念图：** 锁定整体木材色相、帆布灰白、索具深浅关系和表面材质质感。
- **组件设计与参考图：** 同一组件的所有必要视图保持一致的材质分区、色值体系和表面状态。
- **Blender / UE5：** 按本卡建立可运行的 PBR 材质；组件结构由单船合同负责，本卡不改变几何。
