# MAT-001 删除所有做旧驱动规则

## 背景

MAT-001 原版本包含自然旧化、盐雾、日晒、潮湿发暗、踩踏与摩擦、污垢、泛黄、积灰、盐痕、氧化锈蚀、海洋附着物等描述。这些规则会在概念图生成时把“历史材质”放大成明显做旧效果。

## 用户决定

用户明确要求：**删除所有造成“做旧”的规则。**

## 决策

1. MAT-001 不再要求或允许通过使用年限、环境侵蚀或维护痕迹表现旧化。
2. 删除自然旧化、盐雾、日晒褪色、潮湿变色、污垢、磨损、磨光、泛黄、积灰、盐痕、氧化、锈蚀、腐烂、海洋附着物等旧化驱动描述。
3. 保留已经锁定的材质颜色、材质分区和 PBR 粗糙度范围；不新增卡外颜色。
4. 船体、甲板、帆布、索具、铁件和船底均以完整、干净、维护良好的表面状态表现。
5. MAT-001 的 `reference.jpg` 仅保留为来源存档，不得再作为生成输入；后续生成只执行材质卡文字/机器卡中明确写出的规则。
6. `ShipType_SmallSailer01/design.md` 中会触发旧化的“旧帆布”措辞改为“低饱和灰白帆布”。
7. 本 ADR 生效后，被替代版本中的任何旧化措辞不得作为后续生成、重出图或材质解释的有效依据。

## 不变内容

- MAT-001 的颜色参考值不变；
- 木纹、板缝、帆布纤维、绳索纤维等材质可读性要求不变；
- 船只结构不由材质卡修改；
- MAT-001 仍为项目默认木质帆船材质卡。
