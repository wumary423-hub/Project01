# Caravel 小型双桅卡拉维尔帆船

## 1. 定位与数值口径

作为 Cog 之后的第二艘船，承担沿岸贸易兼短途探索。以15世纪后期双桅拉丁帆 Caravel 为历史风格参考，允许架空化调整，不复原特定历史实船。
本稿记录用户确认写入的游戏设计设定，不代表已完成概念图、建模或程序集成验收。资产档案名采用 ShipType_Caravel01；运行时数据表、资源路径及 Socket 合同尚未定义。

| 项目 | 设定 |
|---|---|
| 船体长度 | 21m，按船体首尾计算，不含上层建筑及外伸杆件 |
| 最大船宽 | 6m |
| 满载吃水 | 约2.3m，暂定 |
| 满载排水量 | 约85t，暂定，待模型水下体积校核 |
| 桅杆 | 2根，均位于船体中轴线；前方主桅较大，后方艉桅较小 |
| 帆装 | 2面拉丁三角帆，每桅一面，每面配一根倾斜长帆桁 |
| 船员 | 标准20人，最多28人 |
| 甲板 | 一层连续主甲板，纵向水平，下方为货舱 |
| 艉楼 | 一层小型方形艉楼，地板与主甲板同层，屋顶为露天平台 |
| 货舱口 | 1个，位于两桅之间的船体中轴线上 |
| 楼梯 | 1处，船内紧靠右舷，连接主甲板与艉楼屋顶 |
| 火炮 | 4门轻型火炮，每舷2门 |
| 船舵 | 艉柱悬挂舵，使用舵柄操纵 |

排水量包含船体、装备、船员、补给和货物的总重量，不等于载货量。货物吨位、航速、桅高、帆桁长度、帆面积及精确安装坐标保持 UNSET，待后续设计。

## 2. 结构与外观

- 船体比 Cog 更修长，船首逐渐收窄，中部保留货舱空间。
- 前大后小的双桅、两面拉丁三角帆是主要识别特征；不采用三桅 Niña 帆装。
- 初版不增加顶帆、艏帆或大型瞭望台。
- 主甲板纵向水平是游戏建模简化，不宣称历史甲板均为平面。
- 艉楼内部作为船长室，艉部不再向上叠加房间；船首暂不设置封闭艏楼。
- 深色船壳、浅色甲板、方形艉楼、完整实心舷墙，材质沿用 MAT-001；不做旧、不加锈蚀。
- 继续遵循组件优先流程；现有帆模板先检查兼容性再决定复用或新建。

## 3. 与 Cog 的升级关系

| 项目 | Cog | Caravel |
|---|---:|---:|
| 船体长×宽 | 16×约5.8m | 21×6m |
| 满载吃水（暂定） | 约2m | 约2.3m |
| 满载排水量（暂定） | 约65t | 约85t |
| 标准／最多船员 | 14／20人 | 20／28人 |
| 桅杆／帆面 | 单桅、1面横帆 | 双桅、2面拉丁三角帆 |
| 轻型火炮 | 4门 | 4门 |
| 主要定位 | 基础沿岸贸易 | 沿岸贸易兼短途探索 |

升级重点为船内空间、迎风航行能力和操纵表现，顺风最高速度只计划小幅提升，具体数值尚未确定。
航行范围扩展至更长距离的沿岸探索及条件合适时的短程跨海航行。货运提升幅度待对照实际模型与游戏数据确定。
