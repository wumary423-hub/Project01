## 2026-08-23 — Component-first workflow reset

- 用户废止旧的整船线稿/整船多视图生产链，并要求其不再干扰新流程。
- 保留船只用途、船型、15m 船长、18m 主桅、单桅单甲板、单层艉楼、右舷内部楼梯、单一货舱口、MAT-001 等整体设定。
- 新流程固定为：完整效果概念图 → 部件拆解 → 船身验证 → 其他部件制作/复用 → Blender 组装 → UE5。
- 当前验证对象改为连续无炮窗的 Hull；同时提供一块可手动缩放定位的简单独立 Deck。
- 炮窗改为后续独立逻辑部件，带 Blender Cutter 和火炮锚点；全船仍计划 4 个实例、每舷 2 个。
- 旧视觉母版、线稿、多视图、白模审核图、旧提示词和旧流程脚本从当前工作树移除；历史可从 Git 恢复。
