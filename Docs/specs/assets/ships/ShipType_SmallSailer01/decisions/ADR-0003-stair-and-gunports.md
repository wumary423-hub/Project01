# 单一艉楼楼梯与四炮窗结构

## 用户决定

1. 主甲板通往艉楼平台的楼梯采用**一套木质楼梯**，不得做成左右对称双楼梯。
2. 炮窗属于船体结构特征：全船总计 **4 个炮窗**，左舷 2 个、右舷 2 个。

## 决策

- 艉楼通行结构只设置一套主甲板至艉楼平台的木质楼梯；具体靠左舷或右舷的位置若未在当前规范中锁定，不得自行补成双楼梯。
- 船体炮窗固定为左右舷各 2 个，总计 4 个，并保持两舷对应关系。
- 炮窗数量约束的是船体结构开口，不等同于当前实际安装武器/火炮数量；武装数量在被单独锁定前仍保持 UNSET/未锁定。
- 后续概念图、线稿透视图、线稿多视图、概念多视图、最终多视图与 3D 船体结构均应保持该炮窗数量一致。

## 不采纳内容

本 ADR 只记录用户明确批准的单楼梯与四炮窗结构，不吸收同次图像评审中被用户驳回的其他建议。
