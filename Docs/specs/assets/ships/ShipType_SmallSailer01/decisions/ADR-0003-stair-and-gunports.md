# 单楼梯与四个独立炮窗模块

- 艉楼只使用一套位于船内右舷的楼梯；该楼梯在以后制作艉楼组件时执行。
- 全船规划四个等尺寸炮窗实例，左舷两个、右舷两个。
- 炮窗不得直接切入 Hull。每个炮窗模块包含可见框体/盖板、供 Blender 使用的布尔切割体，以及绑定火炮的锚点或 Socket。
- 炮窗数量不等于火炮数量；武装数量仍未锁定。
