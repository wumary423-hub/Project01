# 锁定船长与主桅绝对尺寸

## 背景

此前船长 15m 仅为概念暂定值，主桅只锁定为 `mast_length > ship_length` 的相对比例约束。

## 用户决定

用户明确锁定：

- 船长：**15m**；
- 主桅长度：**18m**。

## 决策

1. `ShipType_SmallSailer01` 船长固定为 **15m**，不再标记为 PROVISIONAL。
2. 主桅从桅脚到桅顶的结构长度固定为 **18m**。
3. `18m > 15m` 的比例关系成为上述固定尺寸的派生结果，不再作为替代绝对尺寸的主规则。
4. 概念图、线稿透视图、线稿多视图、概念多视图、最终多视图及后续 3D 制作均应遵守这两个固定尺寸。
5. 船宽、吃水、排水量等未明确锁定的尺寸仍保持 UNSET / 未锁定，不得自行推导。

## 后果

- 后续提示词不得再写“船长约 15m”；应直接写“船长 15m”。
- 后续提示词不得只写“主桅大于船长”；应直接写“主桅长度 18m”。
- 修改这两个尺寸需要新的明确设计变更记录。
