# Cog 历史原型与甲板结构约束

## 用户决定

本船新增以下结构规则：

1. 以 **Cog (ship)** 为历史原型；允许架空化调整，不要求一比一复原具体历史实船。
2. 主甲板至艉楼平台仅一套楼梯，楼梯必须靠边贴一侧船舷，不得居中；具体左舷或右舷尚未锁定。
3. 炮窗全船 4 个、每舷 2 个，并以船体纵向中心线为镜像轴，两舷镜像对应分布。
4. 炮窗位于顶层甲板对应的舷侧区域，不得下移至其他甲板层级。
5. 主桅位于纵向中心线，且主桅长度必须严格大于船长：`mast_length > ship_length`。这是相对尺寸约束，不由当前约 15m 的概念船长推导锁定绝对主桅米数。
6. 货舱口只设置 1 个；可由多块盖板组成，但必须读成一个货舱口，且不得与主桅/桅座位置重叠。

## 决策边界

- 炮窗数量是船体结构开口数量，不等于锁定实际安装 4 门火炮。
- 楼梯贴哪一侧船舷目前保持 `UNSET`，不得由工具自行决定并写成长期事实。
- 船长绝对值仍为概念约 15m / `PROVISIONAL`；主桅只锁定相对关系 `> ship_length`。
- 本 ADR 不修改 MAT-001 材质、颜色或表面状态规则。
