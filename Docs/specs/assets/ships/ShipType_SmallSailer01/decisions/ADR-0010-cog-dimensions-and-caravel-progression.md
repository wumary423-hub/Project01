# ADR-0010：更新 Cog 尺寸及第二艘 Caravel 设定

日期：2026-09-11
状态：已获用户明确授权写入仓库
范围：游戏船只资产设计文稿及 Cog 对应参数合同

## 原因与授权

用户明确告知 Cog 现有船体长16m（不含上层建筑）、宽约5.8m，要求调整 Caravel 尺寸并增加排水量。
随后要求补充 Cog 同样式设定，并明确指示“将这两船设定作为设计文稿写入仓库push”。

## 决策

- 以16m船体长度替代旧的15m LOCKED值，宽约5.8m。
- Cog 暂定满载吃水2m、排水量65t，标准14人、最多20人，1面横帆，4门轻炮。
- Caravel 船体21×6m，暂定满载吃水2.3m、排水量85t，标准20人、最多28人，2桅2面拉丁帆，4门轻炮。
- 所有排水量均为游戏设计暂定值，待水下体积校核；不是载货吨位。
- Cog 设计与集成合同版本升为2.0.0，既有18m主桅长度和模块接口保留。
- Caravel 先登记设计文稿，程序集成合同不在本次设定范围内。
- 旧 ADR 与 Changelog 保留作为历史；其中15m及未设定武装等旧值由本决策替代。

## 影响

本次是文档及参数更新，不自动修改 Blender/UE5 模型，不补造航速、载重或新船 Socket。
