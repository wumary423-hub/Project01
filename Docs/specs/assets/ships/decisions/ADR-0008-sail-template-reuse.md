# 船帆及骨架模板复用优先

用户明确要求：“先将这个规则写入文档，以后如果要做新的船帆，先看能不能套用之前的船帆。如果不行再做新的船帆和骨骼。”

决定：将该前置检查写入全局制作规则第 6.1 节，适用于所有后续船帆任务。按“帆型＋收放方式”组织模板；依次尝试直接复用、尺寸／比例变体、最后才是无法适配时的新模板。新建前记录不兼容原因，新建后登记以供复用。

这是 production-rules 2.0.0 第 6 节“复用优先”的非破坏性扩展，版本升为 2.1.0；保留既有组件优先流程，不改变单船尺寸、船体结构、已发布资产或程序接口。规则批准不等于当前船帆候选已获最终美术与性能批准。

权威正文：[全局制作规则](../production-rules.md#61-船帆与骨架先复用后新建)。模板入口：[船帆模板目录](../sails/README.md)。
