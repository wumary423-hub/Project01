# 船只资产制作：概念图必须完整容纳桅杆

## 背景

船只 `[概念图]` 用于确定整体设计调子与主体比例。如果构图把主桅顶部裁出画面，会破坏桅杆高度、船体与桅杆比例以及帆装身份的可读性，并影响后续结构判断。

## 用户决定

用户明确要求：

- `[概念图]` 不得裁剪桅杆；
- 对有主桅的船只，主桅从桅脚到桅顶必须完整出现在画面内；
- 不得为了放大船体主体或适配画幅而把桅顶裁出画面。

## 决策

1. 船只 `[概念图]` 必须完整容纳需要表达的最高桅杆结构，主桅桅顶不得触碰或越过画面裁切边界。
2. 构图时应给桅顶保留合理安全边距，使“完整入画”在生成误差下仍然成立。
3. 如果画幅选择与完整桅杆展示发生冲突，优先保证完整船体与完整桅杆入画，不得通过裁切桅杆解决。
4. 本决定**不锁定 `[概念图]` 的固定长宽比**。长宽比仍未全局规定；如未来需要固定比例，应由用户另行锁定。

## 后果

- 后续概念图提示词必须明确要求完整主桅入画、不得裁切桅顶。
- 当前没有 16:9、4:3、1:1 等全局概念图画幅比例规则。
- 工具需要自行选择画幅时，应选择能够完整容纳船体和最高桅杆的画幅，而不是先固定比例再裁切主体。
