# 船只[概念图]默认不在画面内放文字

## 背景

在船只概念图生成中，图像模型可能自行把提示词中的材质、色号、规则或资产名称排版到画面内，形成标题、说明栏、参数表或乱码文字。这会把单张定调概念图变成 concept sheet，并降低主体船只的视觉可读性。

## 用户决定

用户明确同意：**[概念图]去掉文字。**

## 决策

1. Project01 所有船只资产的 `[概念图]` 默认输出纯画面。
2. 除非用户明确要求图内文字，否则不得在概念图画面内加入：标题、说明文字、规则列表、材质名称、HEX 色号、参数、标签、注释、图例或其他文字排版。
3. 生成提示词中的规则、色值和制作说明只作为模型执行约束，不应被渲染成画面文字。
4. 需要向用户解释规则、材质或设计理由时，应在图片之外用文字回复或设计文档表达。
5. 本规则不禁止后续专门定义的 UI 图、标注图、技术说明图或用户明确要求带文字的产物；只规定 `[概念图]` 的默认表现。

## 后果

- `[概念图]` 保持单张定调关键图的职责；
- Nano Banana、ChatGPT 图像生成及其他视觉工具不得自行把提示词内容排进概念图；
- 该规则写入 `Docs/specs/assets/ships/production-rules.md` 并对所有船只资产生效。
