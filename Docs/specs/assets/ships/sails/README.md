## 船帆命名规则（2026-09-05，用户批准）

船帆按“帆型＋尺寸＋序号”命名；同帆型同尺寸的新资产依次增加序号。同一资产的修改使用修订版本，不另占序号。序号在模板目录中分配，不因换一艘船或复制实例而递增。

- 单位为米，小数点写作 p，名称只用字母、数字、下划线。
- 当前梯形横帆：Square_W9_B9p5_H8_01。W 表示上缘宽，B 表示下缘宽，H 表示设计展开高度；01 为独立资产序号。
- 等宽帆可用 Square_W9_H8_01；登记时应按实际上下缘尺寸统一检索，不能因写法不同重复分配。
- 三角帆用 Triangle_W<基边宽>_H<垂直高度>_<序号>，固定边及收放方式另外登记，不能单凭名称判断兼容。
- 文件内容前缀：SK_ 帆骨骼网格，RIG_ Blender 骨架物体，SKEL_ 骨架数据／UE Skeleton，AN_ 动画。动画后缀使用 Furl、Unfurl、Preview。
- 骨骼内部名称、权重组和动画通道不按帆面尺寸改名，保持模板内部引用；共享材质不必按帆复制。
- 当前资产序号 01；资产修订仍为 r2。此前示例 W9-9p5 改写为 W9_B9p5，明确上／下缘。
